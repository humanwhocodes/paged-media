# Paged Media Polyfill vs. Paged.js

A feature-by-feature comparison of `@humanwhocodes/paged-media` and [Paged.js](https://pagedjs.org) (`pagedjs`), the two JavaScript polyfills for the [CSS Paged Media](https://www.w3.org/TR/css-page-3/), [CSS Fragmentation](https://www.w3.org/TR/css-break-3/), and [CSS Generated Content for Paged Media](https://www.w3.org/TR/css-gcpm-3/) modules.

Paged.js status reflects version 0.5.0-beta.2 (latest on npm: 0.4.3; repository last updated 2026-04-23, 229 open issues) as documented on its [support page](https://pagedjs.org/en/documentation/14-supported-feature-of-the-w3c-specifications/) and as implemented in its source, with links to open issues at [github.com/pagedjs/pagedjs](https://github.com/pagedjs/pagedjs/issues) where behavior is reported broken. Paged Media status reflects the tests in `tests/` (the PagedJS issues below are all covered by `tests/pagedjs-issues.test.ts`) and the probe in [support.md](support.md).

Legend: ✅ supported · ⚠️ partial or with known bugs · ❌ not supported · ➖ not applicable

## Approach

|                     | Paged Media                                                                                                                             | Paged.js                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Target browser      | Chromium (Puppeteer or on screen); relies on Chromium's native paged media support                                                      | Any browser; re-implements pagination even where the browser supports it natively ([#248](https://github.com/pagedjs/pagedjs/issues/248), [#291](https://github.com/pagedjs/pagedjs/issues/291), [#84](https://github.com/pagedjs/pagedjs/issues/84))                                                                                                                    |
| Native features     | Detected with `detectSupport()`; if the document only uses native features nothing is changed                                           | Always paginates                                                                                                                                                                                                                                                                                                                                                         |
| Stylesheet handling | Own CSS parser; unsupported properties become registered custom properties; author selectors are left intact (only `body >` is widened) | css-tree based; rewrites selectors to `data-*` attributes, which changes specificity ([#323](https://github.com/pagedjs/pagedjs/issues/323), [#317](https://github.com/pagedjs/pagedjs/issues/317), [#311](https://github.com/pagedjs/pagedjs/issues/311), [#225](https://github.com/pagedjs/pagedjs/issues/225), [#228](https://github.com/pagedjs/pagedjs/issues/228)) |
| Text splitting      | Line boundaries measured with ranges; content is cloned node by node                                                                    | Character-offset break tokens ([#208](https://github.com/pagedjs/pagedjs/issues/208), [#167](https://github.com/pagedjs/pagedjs/issues/167), [#87](https://github.com/pagedjs/pagedjs/issues/87), [#130](https://github.com/pagedjs/pagedjs/issues/130))                                                                                                                 |
| Print output        | One `@page` per distinct sheet size with zero margins; Puppeteer `preferCSSPageSize: true`                                              | Fixed-size page divs; mixed orientations do not survive `window.print()` ([#281](https://github.com/pagedjs/pagedjs/issues/281), [#141](https://github.com/pagedjs/pagedjs/issues/141), [#6](https://github.com/pagedjs/pagedjs/issues/6), [#174](https://github.com/pagedjs/pagedjs/issues/174))                                                                        |
| Extensibility       | `onPage` callback, `pagedmedia:rendered` event, exported parser and cascade                                                             | Handler classes with hooks for every stage (`beforeParsed`, `afterPageLayout`, …)                                                                                                                                                                                                                                                                                        |
| Preview UI / CLI    | `scripts/render-pdf.js`                                                                                                                 | Previewer, `pagedjs-cli`                                                                                                                                                                                                                                                                                                                                                 |
| Language            | TypeScript, ESM                                                                                                                         | JavaScript                                                                                                                                                                                                                                                                                                                                                               |
| Fonts               | Waits for web fonts before measuring                                                                                                    | ➖                                                                                                                                                                                                                                                                                                                                                                       |

## Summary

Paged Media covers every feature of the three specifications that Chromium lacks except PDF bookmarks and multi-column layout, and hands the rest to the browser. Paged.js covers page geometry, selectors, named pages, running elements and basic cross references well, but its documented gaps (leaders, `target-counters()`, `avoid` breaks, `box-decoration-break`, `counter()` in `string-set`) and its open pagination bugs around tables, counters, preformatted text, floats, and selector rewriting are where the two differ most. In exchange, Paged.js offers a handler/hook system, a previewer, and a CLI, and runs in browsers other than Chromium.
